About Crestr

This is an open-source hiking app built for UK hikers. It allows the planning, saving, loading and downloading of routes through a modern interface without the clutter.

Through open map data and a custom-made routing engine, Crest generates routes between your start and end points. The routing engine favours safer, and greener paths by default, and a filter allows the user to change what type of paths they prefer.
